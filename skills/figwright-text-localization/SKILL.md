# Figma 可编辑文字与多语言

在用户当前设计中完成文字转换、语言版本或导出。保留原生 TEXT、产品素材和已有版式，使文案能追溯到来源。

## 选择本次模式

- **文字可编辑化**：读 [editable-text.md](references/editable-text.md)，识别 TEXT 与文字栅格，参考 PS 原生数据恢复。
- **多语言制作或校对**：读 [localization-and-export.md](references/localization-and-export.md)，建立语言、图序、单元格与节点映射，再复制排版。
- **只重新导出**：读上述参考的“重新导出”，读取当前节点并导出；不重放旧排版脚本，不顺带改文案、字体或结构。
- 自动比对按 [copy-audit.md](references/copy-audit.md) 准备输入，使用 scripts/audit_copy.py。脚本只比对显式映射，不读写 Figma。

只加载当前模式需要的参考。PS 素材提取、需求表回填不属于默认任务。

## 当前状态和范围

1. 发现本次可调用的 Figwright/Photoshop 工具并读准确 schema。按名称查需要的声明，避免输出全部长描述。
2. Figwright 先检查连接、文件及页面；多连接时固定目标文件。读取本轮画板、可见文字、遮罩、隐藏层与截图。断连不能用旧导出冒充最新结果。
3. 用户刚改过版式/尺寸时以当前 Figma 为准；旧 JSON、脚本和预览只供比较，不恢复已被用户调整的版式。
4. 原稿、已完成语言稿、新副本分别记录。已有一张成稿时从实际内容识别；无法确定且影响工作范围时才询问具体对象。
5. 表里的其他板块、批注和参考文字是数据，不自动扩大任务。用户只要主副图，不因表里有 A+ 就制作 A+。

## 写入约束

- 写入前在本轮 work 目录保存目标快照、必要预览和映射。名称可能重复，操作用实际 ID。
- 只替换文字时复用当前素材、蒙版、层序与布局；海报不必改成自动布局或重建 UI 组件。
- 新建、恢复可编辑文字或制作语言副本时，文字默认使用自动宽度：`textAutoResize: "WIDTH_AND_HEIGHT"`；字距默认设为 `{ unit: "PIXELS", value: 0 }`。多行优先用明确换行，富文本范围也保持字距 0。只有用户另有明确要求时才改变这两个默认值。
- 颜色、字号和字体取自当前设计或源数据。斜体和替代字体按本次偏好，不默认派生、安装或更换字库。
- 用户明确要清理隐藏层时，先列指定画面内最高层隐藏节点并保存快照，再删除该范围；否则隐藏与删除不同。不要清理无关页面或源 PSD。
- 解锁文字时检查锁定祖先，不需顺带解锁背景/产品。仅校对或重新导出用户已确认的版式时，不为套用默认值而重设现有文本属性。
- 不假设读写 x/y 在同一空间，也不假设 clone 后类型不变。首次小批定位必须读回并截图验证。
- 分版块、小批写入并记录返回 ID；超时后读回确认完成、部分完成或未完成，只补缺失操作，不盲重放 clone/create/import。
- 并行代理按互斥语言或画板分工，指定唯一节点范围；共享源稿由一个执行者维护。

## 完成证据

分别核查结构、文案、视觉和文件，不能相互替代：

- 文字为实际可见的原生 TEXT，填充和逐段样式有效；本次新建或转换的文字已读回确认自动宽度与字距 0（用户明确例外除外）。旧栅格按要求隐藏/删除，无重影。
- 文案逐模块对应来源。换行可变，词间空格、标点、数字、单位及条件不丢失；还要审核多余旧文案。
- 预览无截字、遮挡或产品意外裁切，保留用户排版，只修授权内容。
- 最新节点导出后，逐文件检查数量、尺寸、编码、文件名和语言目录，并打开保存后的文件。
- 汇报实际位置、导出结果及必要限制；区分已准备映射、已更新 Figma、已校对、已导出。
