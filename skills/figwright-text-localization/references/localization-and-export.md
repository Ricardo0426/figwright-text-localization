# 按表复制语言版本与重新导出

## 映射来源

只读提取对应单元格，记录 sheet、row、cell、语言、稳定 output_id、版块标签、显示图序、源节点、新节点和文件名。

图序可能重复或缺号，“副图9”不等于第九个画板/表行。不按数字补图，不把 A+ 混入主副图。语言按表头和授权范围，不默认固定四语。

每图拆为标题、副标题、数值、说明、卡片和清单项，保留整格原文。数字可能由大号值与说明共同表达，需显式映射。复制已完成语言稿也要查英文残留标题、括号说明和单位。

## 复制当前结构

- 复制当刻再次读源，用户可能同步移动文字/改字号。旧快照不覆盖当前稿。
- 保存 clone 返回 ID，核对树映射。导入的 FRAME clone 可能成为 GROUP；检查蒙版、尺寸和截图，不能仅据类型断言丢失。
- GROUP 子坐标可能是页面/section空间，嵌套 FRAME 又是父级相对空间。先试一个副本文字、读回验证；不套统一减法。
- 脱离源画板的可见文字要同步复制并纳入副本。只 clone 产品底图可能漏掉顶层标题。
- 语言分别组织，保护原稿和用户成稿；命名面向用户，ID用于索引。

## 替换排版

源单元格完整替换，仅调整换行、视觉大小写和列表标记，不另写营销文案。按本轮真实构图确定可用区域：特写卡可能已从底部左右变成右侧上下，不照旧提示放字幕。

先定实际字体，默认设自动宽度 WIDTH_AND_HEIGHT、字距 0，再按可用区域加入语义换行并读实际宽高；不要默认使用固定宽度的 HEIGHT。只有用户明确要求固定宽度或其他尺寸模式时才改用相应模式。优先语义换行和空间利用，再适度改字号。保留完整型号、连字符词、数字单位、平台名，不为两行删除词间空格。

技术卡片逐模块审核；先设正文完整范围基准色，再为 bullet 着色。清单增加时可按授权用两列/增行，不能漏掉条件、适配器、线材、工具、说明书。不要因文字长就缩放合成产品图，变换可能露出烘焙边缘/旧碎片；必要变换须检查全主体及四角。

自动宽度与字距 0 是本技能的文字默认值，应用到本次新建、转换或制作语言副本的文字及富文本范围；用户明确覆盖时遵循用户要求。斜体和解锁按本次指令。仅校对或重新导出已确认版式时，不顺带重设这些属性。

## 核对

使用最新 characters。默认可折叠空白/统一大小写，不删除全部空白，否则 Drive di 与 Drivedi 会被错误判为一致。脚本用法见 [copy-audit.md](copy-audit.md)。

检查所有模块/清单项，单元格和图号正确；重音、标点、数字、单位、条件、品牌和词序完整；富文本末尾字号正常；无旧语言段落。型号/产品印刷/软件截图不强制翻译。

跨节点表达需明确语义顺序，不任意拼凑全图零散词来通过。修正文案后复看预览，补空格也可能增行。

## 重新导出

用户“改好排版，重新导出”时，当前节点是成图来源，不回放 clone/resize/move/旧文字脚本，不顺带优化。

1. 确认插件和正确文件，读取当前画板 ID/尺寸/可见性；旧 manifest 仅供匹配。
2. 按格式/倍率导出本轮暂存目录。JPG实际导出，不改扩展名冒充。
3. 高分辨率图片采用合适小批顺序导出。并行大批可能超时；超时查磁盘成功项和连接，缩批只补缺失项。
4. 打开每个暂存文件检查编码、尺寸、数量、非空内容和命名。
5. 覆盖授权目录时先验证整批成功，再按精确映射覆盖目标；可备份上一批到本轮 work，不递归删目录或无关文件。
6. 读最终输出核对文件数/尺寸/字节或哈希。未改图片哈希相同是正常的，刷新证据须来自本轮成功导出，不能靠旧文件存在。
7. 报告本轮实际结果。断连保留旧输出，说明新一轮未完成，不能称已导出。

导出、文案和视觉审核是不同证据；旧轮次通过不能代替本轮。
